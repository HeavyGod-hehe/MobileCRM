CRM - CHANGES TO BE DONE
=========================
Written: 2026-07-21

This file lists a confirmed bug plus a researched list of features that are
missing from the CRM compared to what other phone-reseller / small-business
CRM software typically offers. Nothing here has been built yet - this is a
backlog to work through.


PART 1 - CONFIRMED BUG: Expense Summary misses expenses added via Accounts
----------------------------------------------------------------------------
What's wrong:
  There are actually THREE ways to record an expense in this CRM, but the
  Expense Summary report only knows about two of them:
    1. Per-phone expenses (repair cost, accessories on a specific phone)
    2. Fixed expenses (rent, salary - recurring overhead)
    3. Recording it as an entry against an "Accounts" (khata) entry marked
       as an expense category

  Expense Summary (database.py, function expense_summary) only reads #1
  and #2. Expenses recorded the 3rd way (#3) DO show up correctly in the
  Cash Book and in that account's own statement - so the money isn't lost
  or miscounted anywhere else - but they silently never appear in the
  Expense Summary report or its totals.

  On top of that, marking an account as an "expense category" in the first
  place is not a real feature in the UI - there's no checkbox for it. The
  only way it currently works is if the Contact field of that account is
  typed EXACTLY as "expense category" (a hidden, undocumented trick).

The fix (2 parts):
  1. Update expense_summary() in database.py to also pull entries from
     expense-category accounts, so all three expense types show up
     together with correct totals.
  2. Add a real "Mark as Expense Category" checkbox to the New Account
     form in Accounts, instead of requiring the hidden Contact-field trick.


PART 2 - MISSING FEATURES (researched against other mobile-shop / small
business CRM software)
----------------------------------------------------------------------------

TIER 1 - High impact, matches how this shop actually works:

  - Staff accounts / role-based permissions
    Right now every login is a full owner account with total access.
    There is no way to give an employee a limited login (e.g. can record
    sales but can't delete records or see full reports). Standard in
    almost every competing CRM.

  - Low-stock / reorder alerts for accessories
    Phones are tracked one-by-one by IMEI (correct, since each phone is
    unique) but accessories like chargers/cases that sell in bulk have no
    stock-count concept at all, so there's no "running low on X" alert.

  - Barcode label PRINTING
    The app can scan a barcode/QR with the camera to look up a phone, but
    there is no way to print a barcode label for a phone or accessory.

  - Automated SMS / WhatsApp payment reminders
    Right now you can only manually share an invoice link over WhatsApp.
    There's no automatic "your udhar payment is due" reminder, which
    several Pakistan-focused mobile shop tools (e.g. CloudPOS) offer.

TIER 2 - Solid additions, medium effort:

  - Warranty tracking with real expiry dates and claim status
    (currently warranty is just free text on the invoice, not an actual
    tracked field with a start date/duration/claim status)

  - Repair ticket workflow
    Phones already have an "In Repair" status, but there's no proper
    ticket system on top of it (status stages, which technician is
    working on it, which parts were used)

  - Make Journal Vouchers and Fixed Expenses editable
    Both currently only support create/list/delete - if you make a typo
    you have to delete and re-add instead of just editing it

  - Charts / graphs on the dashboard
    All current reports are numbers in tables/cards - there are no visual
    trend charts (e.g. monthly profit trend, best-selling models over time)

  - A real first-time walkthrough after signup
    There is already a "Welcome, [name]!" popup after signup, but it's
    just a greeting - it doesn't actually explain what each page
    (Inventory vs Cash Book vs Accounts vs Journal) is for. A simple
    skippable 4-5 slide "what's what" guide would help new users a lot,
    especially given the confusing expense-category trick above.

TIER 3 - Bigger scope, only worth it if the business expands:

  - Multi-shop / multi-branch support (currently one login = one shop only)
  - Trade-in / buyback valuation workflow with device condition grading
    (the existing "Borrow phone from another shopkeeper" feature already
    covers the more common local use case, so this is low priority)
  - Per-report export to CSV/Excel (currently there's only one big JSON
    export of everything, not per-report downloads)

NOT RECOMMENDED right now:
  - Multi-currency / multi-language support - no sign this is needed for
    a single-currency PKR shop
  - Purchase orders / GRN workflows - that's built for bulk-SKU wholesale
    buying, doesn't fit a per-IMEI used/new phone reseller business
